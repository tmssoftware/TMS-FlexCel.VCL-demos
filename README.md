# Examples for FlexCel Studio for VCL and FireMonkey

Here you can find all the demos for [FlexCel Studio for VCL and FireMonkey](http://www.tmssoftware.com/site/flexcel.asp)

You can find a description of each demo in the [documentation](https://doc.tmssoftware.com/flexcel/vcl/index.html)
**All the demos here are also available when you install FlexCel using the setup.**

**:book: Note** We update this repository automatically every time we release a new FlexCel version. So if you have notifications integrated with github, you can subscribe to this feed to be notified of new releases.


## New in v 7.27.1 - September 2026


- **Support for Delphi 13.2. Updated Skia (Linux) to the latest version.** The skia version FlexCel was using to work in Linux wasn't compatible with the new compiler. We've updated SKIA to be the latest version. Note that FlexCel only uses SKIA in Linux, so this only affects the Linux compiler.



## New in v 7.27 - September 2026


- **Support for ETSI PAdES signatures in PDFs generated with FlexCel.** Now FlexCel can generate files signed with ETSI PAdES files as required by the European Union. PAdES B-B and PAdES B-T are supported. See the updated demo [Signing PDFs](https://doc.tmssoftware.com/flexcel/vcl/samples/delphi/printing-and-exporting/signing-pdfs/index.html) for an example.

- **PDF 2.0 Support.** FlexCel can now create PDF 2.0 files (see [TPdfVersion](https://doc.tmssoftware.com/flexcel/vcl/api/FlexCel.Pdf/TPdfVersion.html) enumeration)

- **PDF/A-4 Support.** Now FlexCel can create PDF/A-4 and PDF/A-4f files

- **Ability to Sign but not Certify PDF files.** Previous FlexCel versions would always certify the PDF files when signing them. But sometimes you want to allow future changes and not enforce a policy. The new property [TPdfSignature.Certify](https://doc.tmssoftware.com/flexcel/vcl/api/FlexCel.Pdf/TPdfSignature/Certify.html) allows you to set whether to Certify or not (it defaults to true, so default behavior is the same as in the past)

- **New method MeasureString in class ExcelFile allows you to measure strings.** With the method [MeasureString](https://doc.tmssoftware.com/flexcel/vcl/api/FlexCel.Core/TExcelFile/MeasureString.html) you can now calculate column widths that will fit some strings (including rich format like multiple font sizes)

- **Breaking Change: Security: Removed the ability to create files encrypted with SHA1.** While FlexCel can still read old encrypted files using the SHA1 algorithm, it now will refuse to create them, because SHA1 is broken. You need to use SHA256 or 512 instead.

- **Improved compatibility with reading invalid xlsx files.** Now FlexCel can read conditional formats which have an invalid "=" at the start of the formula, and many other invalid things. Recovery Mode was also improved to be able to recover more invalid files.

- **Bug fix.** Fixed exception when rendering some shapes in corner cases.

- **Bug fix.** We could sometimes write the wrong horizontal displacement when subsetting fonts for PDF. This would end up with some glyphs with the incorrect horizontal position in languages like khmer.

- **Bug fix.** We weren't parsing GDEF tables version 1.2, which some fonts like the updated leelawadee.ttf from ms used. This could end in some wrong ligatures when exporting to pdf using those fonts.

- **Bug fix.** Signed PDFs with comments generated by FlexCel could sometimes show a "Annotations modified" warning in the signature panel of Acrobat reader (even if the files were valid and the signature was shown as valid)

- **Bug fix.** Fixed issues with old xls files created by Excel 97, which don't conform to the modern documentation of the xls file format.

- **Bug fix.** Excel 5 Dialog sheets were not converted correctly from xls to xlsx.
